## 🚀 Featured Projects

### 🔨 RAG Forge — Multi-Strategy RAG Evaluation Platform

<a href="https://github.com/Sakshamm-Thakurr/rag-forge">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Sakshamm-Thakurr&repo=rag-forge&theme=nord&border_color=7dd3fc&title_color=7dd3fc&icon_color=7dd3fc" alt="RAG Forge" />
</a>

Compares 4 retrieval strategies side-by-side with an Answer Arena and automated LLM-as-Judge scoring on Faithfulness, Completeness, and Relevance. Includes a query agent that classifies, routes, and expands queries.

| Layer | Technology |
|-------|------------|
| Retrieval | FAISS, BM25, Hybrid RRF, Sentence-Window, Parent-Document |
| LLM APIs | Gemini, Groq (raw REST, no SDK) |
| Evaluation | LLM-as-Judge, 6 retrieval metrics, token/cost tracking |
| UI | Streamlit analytics dashboard |

🔗 [Code](https://github.com/Sakshamm-Thakurr/rag-forge)

### 🛡️ ScopeGuard — Prompt-Injection Red-Teaming for AI Pentest Agents

<a href="https://github.com/Sakshamm-Thakurr/scopeguard">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Sakshamm-Thakurr&repo=scopeguard&theme=nord&border_color=7dd3fc&title_color=7dd3fc&icon_color=7dd3fc" alt="ScopeGuard" />
</a>

Tests whether malicious web content can hijack an LLM pentest agent: 27 injection payloads, 3 defenses, deterministic scoring, 100 tests. In a pilot on Juice Shop and DVWA, injection caused out-of-scope calls in 8/15 undefended runs; spotlighting cut that to 0/10 (p = 0.008).

| Layer | Technology |
|-------|------------|
| Framework | Python, litellm, Pydantic, pytest |
| Targets | OWASP Juice Shop, DVWA |
| Baseline | Authenticated OWASP ZAP |
| Defenses | Spotlighting, scope enforcer |

🔗 [Code](https://github.com/Sakshamm-Thakurr/scopeguard)
